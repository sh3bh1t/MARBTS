# Figure Artifacts

This directory stores generated plots and visual outputs from local experiments.

Examples:
- trajectory plots
- metric trend charts
- comparison figures for reports

Current comparative report outputs:
- `comparative_report_<run_id_a>_vs_<run_id_b>_compromise_trend.svg`
- `comparative_report_<run_id_a>_vs_<run_id_b>_defense_efficiency.svg`
- `comparative_report_<run_id_a>_vs_<run_id_b>_response_latency.svg`

Generated figure files are gitignored by default.
Only this README is intended to be tracked.
